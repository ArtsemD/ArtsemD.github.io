# artsemd.github.io

Portfolio of Artsem D., Design Engineer. Live at https://artsemd.github.io/

- Vue 3, TypeScript, Vite, Tailwind 4
- Hero is a custom Three.js shader: a glowing artboard frame behind fluted glass, with the design tokens lit by its glow. Pauses off-screen, renders one still frame with `prefers-reduced-motion`.
- Content lives in `src/data/` (projects and profile). Case pages are generated from it at `/work/:slug`.
- Client work is under NDA: names, data and brands on the screens are replaced with samples.

```bash
npm install
npm run dev
npm run build
```
